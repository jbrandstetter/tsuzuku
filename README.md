# Tsuzuku 続く

A small habit tracker with GitHub-style grids, in Catppuccin colours. Schedules work like calendar entries,
so habits don't have to be daily.

Use it: https://jbrandstetter.github.io/tsuzuku/

- **Daily** — streak in days
- **Every N days** — e.g. every other day; the streak holds while no gap between sessions is longer than N days
- **Weekly / Monthly** — X times every M weeks/months (e.g. 3× per week, once every 2 weeks), optionally on planned weekdays
- One-tap check for today, a calendar to log or fix past days, current/best streak, 12-month grid
- Off days that are still on schedule show lightly tinted
- Catppuccin Latte / Frappé / Macchiato / Mocha, or Auto (Latte by day, Mocha at night); 14 accent colours per habit
- Data stays on the device (localStorage); export/import JSON in settings

iPhone: open the URL in Safari → Share → Add to Home Screen.
